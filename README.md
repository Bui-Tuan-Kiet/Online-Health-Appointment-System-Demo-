# Hospital Appointment Booking System

## Project Overview
A web-based hospital appointment booking system developed as an individual graduation project.
The system allows patients to book medical appointments online, while doctors and administrators manage schedules efficiently.

## Technologies Used
- Node.js
- Express.js
- HTML, CSS, JavaScript
- Bootstrap
- SQL Server
- Git, GitHub

## Key Features
- User authentication and authorization
- Patient appointment booking and management
- Doctor schedule management
- Admin system management
- Email or notification support

## Project Role
Individual Developer  
Designed, implemented, and tested the entire system independently.
